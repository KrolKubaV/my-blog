# jadamek.com

Personal website of Jakub Adamek: projects, notes, puzzles and Project Euler
progress. Built with [Astro](https://astro.build), deployed to GitHub Pages
on every push to `master`.

```bash
npm install
npm run dev     # http://localhost:4321
npm run new     # add a post
npm run build
```

How to add posts and everything else: [TUTORIAL.md](TUTORIAL.md).
