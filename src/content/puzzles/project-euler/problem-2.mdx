**Problem:** Find the sum of the even-valued Fibonacci terms not exceeding four million.

## Analysis

The Fibonacci sequence: $F_1 = 1$, $F_2 = 2$, $F_n = F_{n-1} + F_{n-2}$.

Every third Fibonacci number is even. We sum those $\leq 4{,}000{,}000$.

## Solution

```python
a, b = 1, 2
total = 0
while b <= 4_000_000:
    if b % 2 == 0:
        total += b
    a, b = b, a + b
print(total)  # 4613732
```
