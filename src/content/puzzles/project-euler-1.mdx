**Problem:** Find the sum of all the multiples of 3 or 5 below 1000.

## Analysis

We need to find:

$$S = \sum_{\substack{k=1 \\ 3 \mid k \text{ or } 5 \mid k}}^{999} k$$

Using inclusion-exclusion:

$$S = \sum_{\substack{k=1 \\ 3 \mid k}}^{999} k + \sum_{\substack{k=1 \\ 5 \mid k}}^{999} k - \sum_{\substack{k=1 \\ 15 \mid k}}^{999} k$$

## Formula

The sum of multiples of $d$ below $n$ is:

$$\sum_{\substack{k=1 \\ d \mid k}}^{n-1} k = d \cdot \frac{m(m+1)}{2}$$

where $m = \lfloor \frac{n-1}{d} \rfloor$.

## Solution

```python
def sum_of_multiples(d, n):
    m = (n - 1) // d
    return d * m * (m + 1) // 2

n = 1000
result = sum_of_multiples(3, n) + sum_of_multiples(5, n) - sum_of_multiples(15, n)
print(result)  # 233168
```

## Answer

$$S = \frac{3 \cdot 332 \cdot 333}{2} + \frac{5 \cdot 199 \cdot 200}{2} - \frac{15 \cdot 66 \cdot 67}{2} = 233168$$
