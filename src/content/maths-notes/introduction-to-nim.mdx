**Nim** is one of the most well-known combinatorial games. Two players take turns removing objects from heaps, and the player who takes the last object wins (in normal play).

## Rules

- There are $n$ heaps with $h_1, h_2, \ldots, h_n$ objects
- On each turn, a player removes one or more objects from a single heap
- The player who takes the last object wins

## Strategy

The key insight is the **Nim-sum** — the XOR of all heap sizes.

$$\text{Nim-sum} = h_1 \oplus h_2 \oplus \cdots \oplus h_n$$

**Theorem:** A position is a losing position (for the player whose turn it is) if and only if the Nim-sum is zero.

## Example

Consider heaps of sizes $(3, 5, 7)$:

$$3 \oplus 5 \oplus 7 = 011_2 \oplus 101_2 \oplus 111_2 = 001_2 = 1 \neq 0$$

Since the Nim-sum is non-zero, this is a winning position. A winning move is to reduce the heap of 7 to 6:

$$3 \oplus 5 \oplus 6 = 011_2 \oplus 101_2 \oplus 110_2 = 000_2 = 0$$

## Python Implementation

```python
def nim_sum(heaps):
    result = 0
    for h in heaps:
        result ^= h
    return result

def winning_move(heaps):
    target = nim_sum(heaps)
    if target == 0:
        return None  # Losing position
    for i, h in enumerate(heaps):
        new_h = h ^ target
        if new_h < h:
            return (i, h - new_h)
    return None

# Example
heaps = [3, 5, 7]
print(f"Nim-sum: {nim_sum(heaps)}")
print(f"Winning move: {winning_move(heaps)}")
```
